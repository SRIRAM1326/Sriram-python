# Simple Quiz Game

## Description
A multiple-choice quiz application that tests knowledge with 10 questions and calculates the final score.

## Features
- At least 10 questions
- Four options per question
- Accept user's answer
- Validate the answer
- Calculate score
- Display correct answers
- Display final percentage
- Allow the user to play again

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Python Quiz ===

Question 1:
Which keyword is used to define a function?
A. function
B. def
C. func
D. define

Your answer: B

Correct!
```
