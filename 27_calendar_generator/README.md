# Calendar Generator

## Description
A tool to display a monthly or yearly calendar for any given year.

## Features
- Ask for year
- Display the entire year's calendar
- Allow displaying a specific month
- Validate year/month input
- Exit option

## Technologies
- Python 3
- `calendar` module

## How to Run
```bash
python main.py
```

## Example
```text
=== Calendar Generator ===

1. Display Month
2. Display Year
3. Exit

Choose: 1

Enter year: 2026
Enter month: 10

     October 2026
Mo Tu We Th Fr Sa Su
          1  2  3  4
...
```
