# Employee Manager

## Description
A beginner-friendly employee management system using Python classes and object-oriented programming concepts.

## Features
- Add employee
- View employees
- Search employee
- Update employee
- Delete employee
- Display employee details
- Calculate average salary
- Exit

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Employee Manager ===

1. Add Employee
2. View Employees
3. Search Employee
4. Update Employee
5. Delete Employee
6. Average Salary
7. Exit

Employee ID: 101
Name: Sriram
Department: Technology
Position: Python Developer
Salary: 35000

Employee added successfully.
```

## What I Learned
- Structuring data logic inside a Python `class`.
- Using `__init__` constructor methods and object instances.
- Integrating object-oriented structures into standard menu-driven flows.
