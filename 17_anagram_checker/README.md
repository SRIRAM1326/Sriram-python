# Anagram Checker

## Description
A utility that checks whether two words or phrases are anagrams (formed by rearranging the same letters).

## Features
- Ask for two words or sentences
- Ignore spaces
- Ignore capitalization
- Compare the characters
- Display whether they are anagrams
- Allow repeated checks

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Anagram Checker ===

First text: listen
Second text: silent

Result: They are anagrams.
```

## What I Learned
- Cleaning strings (replacing characters, lowering case).
- Using Python's `sorted()` function to compare sequences of characters.
