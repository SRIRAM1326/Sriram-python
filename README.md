# Python Mini Projects Collection 🚀

Welcome to the **Python Mini Projects** repository! This collection features **40 independent, beginner-friendly Python CLI applications**. These projects are designed to help you practice and master fundamental Python concepts, data structures, algorithms, and standard library modules.

## 🛠 Requirements
- **Python 3.x**
- No external dependencies required! Every project is built using only Python's built-in standard library.

## 🚀 How to Run
Each project is self-contained in its own folder. To run any project:
1. Navigate into the specific project folder.
2. Run the `main.py` file.

Example:
```bash
cd 01_calculator_cli
python main.py
```

Each project also contains its own localized `README.md` explaining the implementation context and exactly what you'll learn!
