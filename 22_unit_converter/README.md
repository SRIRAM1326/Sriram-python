# Unit Converter

## Description
A menu-based CLI tool to convert various units of measurement.

## Features
- Convert Kilometers <-> Miles
- Convert Meters <-> Feet
- Convert Kilograms <-> Pounds
- Menu-based interface
- Accept decimal values
- Validate input
- Allow repeated conversions
- Exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Unit Converter ===

1. Kilometers -> Miles
2. Miles -> Kilometers
...

Choose an option: 1
Enter value to convert: 5
5.0 km = 3.1069 miles
```
