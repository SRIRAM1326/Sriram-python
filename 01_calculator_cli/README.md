# Calculator CLI

## Description
A simple command-line calculator that can perform basic arithmetic operations: addition, subtraction, multiplication, and division.

## Features
- Addition, Subtraction, Multiplication, Division
- Handle division by zero
- Accept user input from the terminal
- Perform multiple calculations
- Exit option
- Validate invalid input gracefully

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example Usage
```text
=== Calculator ===

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

Choose an option: 1
Enter first number: 10
Enter second number: 5
Result: 15.0
```
