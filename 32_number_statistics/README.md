# Number Statistics

## Description
A number statistics calculator that takes a list of numbers and calculates standard statistical metrics.

## Features
- Accept multiple numbers
- Calculate Minimum, Maximum, Sum, Average, Median, Count
- Display results clearly
- Validate input
- Allow repeated calculations
- Exit option

## Technologies
- Python 3
- Python Standard Library (`statistics` module)

## How to Run
```bash
python main.py
```

## Example
```text
=== Number Statistics ===

Enter numbers:
10 20 30 40 50

Count: 5
Minimum: 10
Maximum: 50
Sum: 150
Average: 30
Median: 30
```

## What I Learned
- Leveraging the standard `statistics` module to calculate mean and median.
- Using built-in math functions `min()`, `max()`, and `sum()`.
