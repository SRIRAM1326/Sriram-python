# Prime Number Checker

## Description
A utility that checks if a given integer is a prime number.

## Features
- Accept an integer
- Determine whether it is prime
- Display the result
- Handle numbers less than 2
- Allow repeated checks
- Exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Prime Number Checker ===

Enter number: 17

17 is a prime number.
```
