# Temperature Converter

## Description
A menu-based CLI tool to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Features
- Menu-based interface
- Accept decimal values
- Validate input
- Display the converted temperature
- Allow repeated conversions
- Exit option
- Supports Celsius, Fahrenheit, and Kelvin

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example Usage
```text
=== Temperature Converter ===

1. Celsius -> Fahrenheit
2. Fahrenheit -> Celsius
3. Celsius -> Kelvin
4. Kelvin -> Celsius
5. Fahrenheit -> Kelvin
6. Kelvin -> Fahrenheit
7. Exit

Choose: 1

Enter temperature value: 37
37.0°C is 98.60°F
```
