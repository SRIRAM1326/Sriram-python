# Random Name Picker

## Description
A program that stores a list of names and randomly selects one when prompted.

## Features
- Allow the user to enter multiple names
- Store names in a list
- Randomly select one name
- Display the selected name
- Allow another selection
- Option to remove a selected name
- Option to clear the list
- Exit option

## Technologies
- Python 3
- Python Standard Library (`random` module)

## How to Run
```bash
python main.py
```

## Example
```text
=== Random Name Picker ===

Names:
1. Sriram
2. Arun
3. Kumar
4. Ravi

Pick a random name

Selected:
>>> Arun
```
