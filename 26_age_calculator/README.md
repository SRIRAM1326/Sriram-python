# Age Calculator

## Description
A utility that calculates the user's current age in years and displays the date of their next birthday.

## Features
- Ask for date of birth
- Calculate current age
- Display next birthday date
- Validate date input
- Handle future birth dates

## Technologies
- Python 3
- `datetime` module

## How to Run
```bash
python main.py
```

## Example
```text
=== Age Calculator ===

Enter date of birth (DD-MM-YYYY): 15-08-2000

Age: 26 years

Next birthday: 15-08-2027
```

## What I Learned
- Parsing date strings using `datetime.strptime()`.
- Performing arithmetic with dates and handling leap year edge cases.
