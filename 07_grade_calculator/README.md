# Grade Calculator

## Description
A student grade calculator that takes marks for multiple subjects and calculates the total, percentage, and corresponding grade.

## Features
- Ask for student name
- Accept marks for multiple subjects
- Calculate total marks, average, percentage, and grade
- Display a formatted result
- Validate marks between 0 and 100

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example Usage
```text
=== Grade Calculator ===

Student Name: Sriram

Python: 85
Database: 78
Mathematics: 91

Total: 254.0/300
Percentage: 84.67%
Grade: A
```
