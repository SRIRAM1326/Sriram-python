# Multiplication Table Generator

## Description
A simple tool that generates a multiplication table for a given number up to a specified limit.

## Features
- Ask for a number
- Ask how far the table should go
- Generate the multiplication table
- Allow repeated tables
- Exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Multiplication Table ===

Enter number: 7
Enter limit: 10

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...
7 x 10 = 70
```
