# Word Counter

## Description
A command-line tool to analyze text and count words, characters, and sentences.

## Features
- Ask the user to enter text
- Count total words
- Count characters including spaces
- Count characters excluding spaces
- Count sentences
- Display the results
- Allow the user to analyze multiple texts
- Provide an exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Word Counter ===

Enter text:
Python is easy to learn. Python is powerful!

Words: 8
Characters: 47
Characters without spaces: 40
Sentences: 2
```
