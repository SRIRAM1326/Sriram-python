# Palindrome Checker

## Description
A program that checks whether a given word or phrase is a palindrome (reads the same backward and forward), ignoring case, punctuation, and spaces.

## Features
- Accept a word or sentence
- Ignore spaces
- Ignore punctuation
- Ignore uppercase/lowercase differences
- Determine whether the input is a palindrome
- Allow repeated checks
- Exit option

## Technologies
- Python 3
- `string` module

## How to Run
```bash
python main.py
```

## Example
```text
=== Palindrome Checker ===

Enter text: Madam

Result: This is a palindrome.
```

## What I Learned
- Using string slicing `[::-1]` for reversing strings.
- Filtering characters using the `string` module constants.
