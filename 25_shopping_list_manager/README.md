# Shopping List Manager

## Description
An in-memory command-line manager to keep track of a shopping list.

## Features
- Add item
- Remove item
- Search item
- View all items
- Mark item as purchased
- Clear list
- Exit

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Shopping List ===

1. Add Item
2. Remove Item
...

Choose an option: 4

=== Shopping List ===
1. [ ] Milk
2. [✓] Bread
3. [ ] Eggs
```
