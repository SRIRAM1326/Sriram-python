# Dice Simulator

## Description
A simple terminal-based dice simulator that allows rolling one or more standard six-sided dice.

## Features
- Roll a standard six-sided dice
- Display the result for each die
- Ask how many dice to roll
- Calculate the total
- Keep track of roll statistics during the session
- Option to exit

## Technologies
- Python 3
- `random` module

## How to Run
```bash
python main.py
```

## Example Usage
```text
=== Dice Simulator ===

How many dice? 3

Results:
Dice 1: 4
Dice 2: 6
Dice 3: 2

Total: 12
```

## What I Learned
- Generating random numbers with the `random` module.
- Using lists to store multiple results.
- Maintaining running statistics across multiple iterations in a loop.
