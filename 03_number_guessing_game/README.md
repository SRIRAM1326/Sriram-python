# Number Guessing Game

## Description
A classic number guessing game where the computer selects a random number and the player has to guess it.

## Features
- Generate a random number between 1 and 100
- Tell the player whether the guess is too high, too low, or correct
- Count the number of attempts
- Allow the player to play again
- Validate invalid input

## Technologies
- Python 3
- `random` module

## How to Run
```bash
python main.py
```

## Example Usage
```text
=== Number Guessing Game ===

I selected a number between 1 and 100.

Your guess: 50

Too high!

Your guess: 25

Too low!

Your guess: 37

Correct!

Attempts: 3
```
