# Character Frequency Counter

## Description
A tool to count how many times each character appears in a given text.

## Features
- Accept text
- Count how many times each character appears
- Option to ignore spaces
- Display character frequencies
- Allow repeated analysis
- Exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Character Frequency ===

Enter text: hello
Ignore spaces? (y/n): y

h : 1
e : 1
l : 2
o : 1
```

## What I Learned
- Using Python dictionaries to tally counts.
- Iterating through strings character by character.
