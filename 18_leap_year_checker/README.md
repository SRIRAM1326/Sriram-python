# Leap Year Checker

## Description
A script that determines whether a given year is a leap year based on the Gregorian calendar rules.

## Features
- Ask for a year
- Determine whether it is a leap year
- Allow checking multiple years
- Validate numeric input
- Exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
=== Leap Year Checker ===

Enter year: 2028

2028 is a leap year.
```
