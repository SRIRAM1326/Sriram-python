# Rock Paper Scissors

## Description
A terminal-based Rock Paper Scissors game against the computer.

## Features
- Player chooses Rock, Paper, or Scissors
- Computer chooses randomly
- Determine winner
- Track player wins, computer wins, and draws
- Allow multiple rounds
- Display final score
- Exit option

## Technologies
- Python 3
- `random` module

## How to Run
```bash
python main.py
```

## Example
```text
=== Rock Paper Scissors ===

1. Rock
2. Paper
3. Scissors
4. Exit

Your choice: 1

You: Rock
Computer: Scissors

You win!
```
