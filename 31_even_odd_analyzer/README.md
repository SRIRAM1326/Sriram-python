# Even/Odd Analyzer

## Description
A command-line program that analyzes a list of numbers to separate them into even and odd categories, and counts the totals.

## Features
- Ask the user to enter multiple numbers
- Separate even and odd numbers
- Display all even numbers
- Display all odd numbers
- Count even numbers
- Count odd numbers
- Display the total number of values
- Handle invalid input
- Allow the user to analyze another list
- Exit option

## Technologies
- Python 3
- Python Standard Library

## How to Run
```bash
python main.py
```

## Example
```text
=== Even/Odd Analyzer ===

Enter numbers separated by spaces:
10 15 22 31 44 50

Even Numbers:
10 22 44 50

Odd Numbers:
15 31

Even Count: 4
Odd Count: 2
Total: 6
```
