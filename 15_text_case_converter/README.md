# Text Case Converter

## Description
A tool that takes text input and converts it into uppercase, lowercase, title case, and sentence case simultaneously.

## Features
- Accept text from the user
- Display all available conversions
- Allow repeated conversions
- Exit option

## Technologies
- Python 3

## How to Run
```bash
python main.py
```

## Example
```text
Input:
python is powerful

Uppercase:
PYTHON IS POWERFUL

Lowercase:
python is powerful

Title Case:
Python Is Powerful

Sentence case:
Python is powerful
```

## What I Learned
- Utilizing built-in string methods like `upper()`, `lower()`, `title()`, and `capitalize()`.
